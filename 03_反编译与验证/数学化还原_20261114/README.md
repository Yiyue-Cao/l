# 本轮数学化还原证据

19 篇最终说明与各自 `.so` 成对保存在 [策略库与详细解读](../../01_策略库与详细解读/19个策略_数学化还原索引.md)。本目录只保存探测、机器码比较与生成过程，不能作为完整策略源码替换原插件。

- `probe_all_configs.py`：隔离调用真实配置解析器，两个浮点标记交叉定位，识别 Option None，避免未初始化载荷误报；SoS 使用明确列出的必需字段种子。
- `probe_nested.py`：分别覆盖 phase/section 数值字段。
- `validate_leaves.py`：逐库点触发、动态阈值、HIGH 主动比例；另记录报价数量的整数标签与浮点返回值。
- `validate_quotes.py`：SM1/SM4 报价类型与价格验证；SM2 原始优化器输出与残差观察。SM2 尾部观察不计作通过案例。
- `validate_sm3_formula.py`：SM3 四动作、B 三态的完整报价分段，2400 案例。
- `validate_state_kernels.py`：九个商品库波动/价差统计、三库阶段切换、两库可覆盖盘口量。
- `validate_special.py`：SM3 可读矩阵、SM3.1 被动门控、SoS6 四阈值平移。
- `extract_all_k1.py`：逐库初始化内嵌常量表并读取 LOW/HIGH 参数 ID 映射；不调用行情或交易回调。
- `build_math_docs.py`：结合人工核对的分支、字段布局、独立数值回执生成 19 篇同名 Markdown。

运行环境：Linux x86-64；通过 ctypes 装载下载的原始 `.so`；依赖 SDK 符号以桩提供，日志 no-op，其余接口一经误调用即 abort。配置探测会调用 create_strategy/on_begin，机器码公式验证不调用信号、行情、订单或历史回测入口。未使用市场数据、历史误差或独立验证集。

本轮核验覆盖的指定计算为 56740/56740。额外的 160 个复合返回矩阵记录、60 个 SM3 可读报价矩阵和 60 个 SM2 优化器观察不混入该计数。读取常量表的 3339 个条目也不冒充验证案例。

仍未完成完整 SDK 订单事件等价回放。A/B barrier 时序、LF4 所有失败路径、SoS 账户复合返回值的完整语义、某些窗口缓存更新与通用引擎费用/账户接续，按各库文中限定，不宣称已全部确定。原加密配置未解密，支持参数不代表历史启用。
