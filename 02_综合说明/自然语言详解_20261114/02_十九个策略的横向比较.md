# 19 个策略的机制对照

比较对象是二进制中已确认的机制，不是版本优劣或历史收益。每个策略的公式、边界和证据见 [逐库索引](../../01_策略库与详细解读/19个策略_数学化还原索引.md)。

## 各策略改变的核心对象

| 策略 | 核心机制 | 与相近实现的差别 |
|---|---|---|
| comm2 | PV 变换、窗口、LOW/HIGH 与 K1、主动交易 | 基础执行链，无 comm3 的 LOW 独立阈值和 maker 管理 |
| comm3 | LOW 独立阈值、skip/maker 路由和挂单维护 | 行情分组进一步决定执行方式；缺省 LOW 阈值继承普通值 |
| comm3_1 | HIGH 幅度结合信号余量、半价差和 tanh 上限 | 改变主动报价函数 |
| comm3_2 | 大半价差前置判断 | 超限返回调用方给定幅度，后续行为仍由调用方决定 |
| comm4 | watcher 收益驱动三阶段 | 按阶段逐字段覆盖参数 |
| comm4_1 | 交易数升级门槛、报价可覆盖的盘口量 | 降级不受交易数门槛限制；一档与后续档计量规则不同 |
| comm5 | 阶段规模倍率、历史收益 XS 排名 | 初始化冻结金额倍率；零倍率另行阻止开仓动作 |
| comm_maker1 | 双侧目标量与报价计算，PV4 信号带 | 分开计算新增量和反向平仓量；盘口 cap 参数不等同 SM1 |
| comm_mock | 交易及收益、金额、持仓等状态发布 | 保留真实下单路径；观察身份由部署配置决定 |
| lf4 | 目标任务、价格范围、截止时间、完成量 | 重试分支不递增次数槽，配置次数不构成实际次数上限 |
| sm1 | 信号带触发，再按超额／半价差选 Taker、Maker、Mid | 规则式报价与盘口量约束 |
| sm2 | 正态概率型效用与数值最优报价 | 先比较两侧效用，再按获选侧门槛确定动作 |
| sm3 | A 定动作，B 改变一次报价决策 | B 可优先压制主动报价；没有 SM3.1 的完整等待配置 |
| sm3_1 | B 时效、A 等待、veto、boost、被动退档与撤单门控 | 核心差别是门控条件及事件顺序 |
| sm4 | 虚拟配对时长中位数选阈值，接 SM 报价 | 优化的是阈值的持有时长统计 |
| sos5 | watcher 驱动三 section，支持金额／篮子 bp 门槛 | section 可改变合约、信号、门槛和风险设置 |
| sos6 | 三 section 加外部四阈值整组平移 | 保留各段原始阈值差；无 SoS5 的 live_basket_bp 参数组 |
| tm5 | 主动交易、订单回报收益滚动队列 | 回报入队，行情回调按 SDK 时间发布 |
| tm6 | TM 型交易与收益队列，加候选时长选阈值及发布 | 与 SM4 的候选机制同类，外围执行不同 |

## 同一变化怎样影响不同策略

| 输入或状态变化 | 可能受影响的机制 | 必须保留的条件 |
|---|---|---|
| 行情分组变化 | comm 的 K1、阈值或执行方式 | LOW/HIGH 由波动／半价差统计决定，不能仅凭价差宽窄判定 |
| watcher 收益跨界 | comm4/4.1/5 的 phase，SoS 的 section | 严格性、原状态、交易数或账户符号各自参与判断 |
| XS 文件被改写 | comm5 初始化评分 | 已初始化对象不随普通跨日回调重排；成功重新初始化才加载 |
| B 更新或变旧 | SM3/SM3.1 报价及门控 | SM3.1 的缓存复用、等待与事件触发超时单独实现 |
| 虚拟配对时长变化 | SM4/TM6 有效阈值 | 选与目标时长最近的中位数；键 0 无有效样本则回退 |
| 无新回报、仅来行情 | TM5/TM6 rolling_pnl | SDK 时间推进可淘汰队首旧记录，再发布新和 |

## 复原时最易混淆的差异

- comm 阶段覆盖不包含 LOW 四阈值及平仓上限；comm5 的正阶段倍率以全局净金额为基数。
- SM1/SM4 的 Maker 辅助报价两侧均使用 `min(b+0.2,a-0.2)`；SM3 卖侧使用 `max`。
- SM4/TM6 的样本来自虚拟信号配对，拒单不回滚；选择目标是时长，不能替换成收益最大化。
- SM3.1 先消费等待 A 再决策；LF4 先保存任务再首次发单。两者失败后保留的状态不同。
- TM5/TM6 在行情回调发布收益；comm_mock 的发布口径和键不同。真实部署连接须由配置确认。

功能支持不等于历史启用。完整撮合、费用、账户接续与回报顺序尚未等价回放，范围见 [事件验证与缺口](10_事件状态机与剩余缺口.md)。
