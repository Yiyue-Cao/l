# 工具脚本

[历史脚本](历史脚本/) 收纳原先散落顶层的 Python 和 Ghidra Java 脚本。与配置探测、数值核验紧密相关的脚本仍放在 [数学化还原证据](../03_反编译与验证/数学化还原_20261114/)。

全部既有脚本保留原始字节，部分依赖原目录相对位置，部分硬编码 Linux 远端路径。不要直接在新目录下运行旧生成器以覆盖当前文档。

[恢复整理前副本.py](恢复整理前副本.py) 可核验保留情况，或在独立新目录导出整理前的完整副本（含整理前 Markdown）。恢复工具本身不执行下载、反编译或回测。

```bash
python3 LOCAL_WORKSPACE/1008/l/05_工具脚本/恢复整理前副本.py --check
python3 LOCAL_WORKSPACE/1008/l/05_工具脚本/恢复整理前副本.py --output /tmp/l_before_organization
```

输出目录必须尚不存在且位于当前资料目录之外。恢复后仍需按历史脚本原本的环境要求配置 Linux x86-64、Ghidra、SDK 桩和路径；恢复目录结构不代表自动获得这些运行依赖。

早期分析精简后，恢复工具会结合目录外的归档包读取旧稿。请将 `1008/l` 与 `1008/l_历史归档` 一并保留，才能继续导出完整原布局。
